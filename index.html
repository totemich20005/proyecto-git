Proyecto Práctico de Git y GitHub

Ejercicio desarrollado con HTML, CSS, Git y GitHub.

Sobre el proyecto

Este proyecto fue creado para practicar el uso de Git y GitHub, incluyendo commits, ramas, fusiones y resolución de conflictos.

Tecnologías utilizadas

  • HTML
  • CSS
  • Git
  • GitHub
  • PowerShell

Objetivo

Comprender el funcionamiento del control de versiones y el trabajo colaborativo mediante repositorios locales y remotos.
