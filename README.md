# Proyecto de Práctica Git y GitHub

Este repositorio fue creado con el objetivo de practicar los conceptos fundamentales de **Git y GitHub**, utilizando Visual Studio Code y PowerShell para gestionar el control de versiones de un proyecto.

## 📌 Descripción

El proyecto contiene ejemplos básicos desarrollados en **Java** y **Python**. A través de estos archivos se practican diferentes operaciones de Git, como la creación de commits, el manejo de ramas, la integración de cambios y la sincronización con un repositorio remoto en GitHub.

## 📂 Estructura del proyecto

El repositorio contiene los siguientes archivos:

- `Ejemplo.java`: ejemplo básico desarrollado en Java.
- `Ejemplo.py`: ejemplo básico desarrollado en Python.
- `.gitignore`: archivo utilizado para indicar qué archivos o carpetas no deben ser incluidos en el repositorio.
- `README.md`: documentación general del proyecto.

## 💻 Tecnologías utilizadas

- Git
- GitHub
- Visual Studio Code
- PowerShell
- Java
- Python

## 🌿 Manejo de ramas

Durante el desarrollo del proyecto se creó una rama llamada `nueva-caracteristica`.

En esta rama se realizó una modificación en el archivo `Ejemplo.java`, agregando una nueva característica al programa.

Posteriormente, los cambios fueron guardados mediante un commit, enviados al repositorio remoto y finalmente integrados en la rama principal `main`.

## 🔄 Flujo de trabajo realizado

Durante la práctica se realizaron diferentes operaciones de Git:

1. Creación del repositorio.
2. Configuración del repositorio remoto.
3. Creación de archivos Java y Python.
4. Uso de `git add` para preparar cambios.
5. Creación de commits.
6. Uso de `git push` para enviar cambios a GitHub.
7. Creación y manejo de una nueva rama.
8. Modificación del código dentro de la rama.
9. Integración de cambios mediante `git merge`.
10. Sincronización entre el repositorio local y GitHub.
11. Eliminación de ramas después de completar su integración.

## 🎯 Objetivo

El objetivo principal de este proyecto es comprender de manera práctica cómo funciona un sistema de control de versiones y cómo Git permite registrar, organizar y administrar los cambios realizados durante el desarrollo de un proyecto.

También permite comprender la relación entre un repositorio local y un repositorio remoto alojado en GitHub.
